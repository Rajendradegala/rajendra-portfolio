RAJENDRA DEGALA — PORTFOLIO STARTER

HOW TO RUN
1. Extract this ZIP file.
2. Open the rajendra-portfolio folder in VS Code or Eclipse.
3. Open index.html in your browser. (Recommended: use the VS Code Live Server extension.)

BEFORE PUBLISHING — PERSONALIZE THESE ITEMS
1. Replace "your.email@example.com" with your real email address (search in index.html).
2. Replace the # links for LinkedIn and GitHub with your profile URLs.
3. Add your resume PDF at: assets/Rajendra_Degala_Resume.pdf
   Create an "assets" folder if it does not exist.
4. Review the skills and project descriptions. Keep only technologies and project details you can confidently explain.
5. Add real screenshots and GitHub/demo links to your projects.
6. Remove the Font Awesome script tag in index.html if you are not using an icon kit; this starter uses text/CSS icons.

FILES
- index.html: all portfolio content and sections
- style.css: dark theme, layout, responsive styles and animations
- script.js: mobile navigation, reveal animations and current year

This is a static HTML/CSS/JavaScript site. No backend or build command is required.
